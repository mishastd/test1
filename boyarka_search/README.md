# Поиск дома около Боярки (DIM.RIA + OpenStreetMap)

Критерии (все настраиваются флагами):

| Критерий | По умолчанию | Флаг |
|---|---|---|
| Радиус от Боярки | 30 км | `--radius` |
| Цена | ≤ 35 000 $ | `--max-price` |
| Больница/поликлиника, аптека, магазин | ≤ 5 км | `--amenity-km` |
| Нет промзон, заводов, складов, военных объектов | в радиусе 10 км | `--clear-km` |

Источники:
* **DIM.RIA API** (`developers.ria.com`) — объявления о продаже домов в Киевской обл., координаты, цена в USD.
* **OpenStreetMap / Overpass API** — больницы, поликлиники, амбулатории, аптеки, магазины,
  а также `landuse=industrial|military`, `military=*`, `man_made=works`, `industrial=*`,
  здания `industrial|warehouse|factory`. Расстояние до промзоны считается до границы полигона.

## Запуск (бережно к лимиту API — 100 запросов)

```bash
cd boyarka_search
python3 search.py                       # 1) пробный запуск: только OpenStreetMap, 0 запросов к RIA
export RIA_API_KEY=ваш_ключ             #    ключ не хранится в репозитории
python3 search.py --go                  # 2) реальный поиск, не больше 40 запросов за запуск
```

Как экономятся запросы:
1. **Сначала бесплатный анализ OSM.** Скрипт находит сёла и города в радиусе 30 км и проверяет их по центру
   (больница/аптека/магазин ≤ 5 км, промзон/военных нет в радиусе 10 км с допуском 2 км).
   Если ни один пункт не подходит — скрипт останавливается, **не потратив ни одного запроса**.
2. **1 запрос** — справочник населённых пунктов RIA (чтобы получить `city_id`).
3. **1 запрос на пункт** — поиск домов до 35 000 $ только в подходящих пунктах (не больше `--max-places 15`).
4. **1 запрос на объявление** — координаты и цена; каждый дом затем проверяется точно по своим координатам.
5. Счётчик запросов хранится в `cache/ria_budget.json` и учитывает все запуски (`--budget 100`).
   Лимит на один запуск — `--max-requests 40`. Все ответы кешируются: повторный запуск
   ничего не перезапрашивает, а продолжает с того места, где кончился лимит.
   **Не удаляйте папку `cache/`** — иначе счётчик обнулится и запросы пойдут заново.

Результат: `results.csv` (открывается в Excel) и `results.html` (карта: зелёные — подходят, оранжевые — нет, с причиной).

Если ни один пункт не проходит строгий фильтр (около Киева промзоны есть почти везде в радиусе 10 км),
ослабьте его — это проверяется бесплатно, без `--go`:

```bash
python3 search.py --min-industrial-ha 5      # игнорировать промзоны меньше 5 га
python3 search.py --clear-km 5               # чистый радиус 5 км
```

## Ограничения
* С 2022 г. военные объекты в OSM по Украине частично удалены — отсутствие военной части на карте не гарантирует её отсутствие.
* В OSM отмечены не все магазины/аптеки в сёлах — перед выездом проверьте по Google Maps.
* ID категорий DIM.RIA: категория 4 = дома, тип 5 = дом, 6 = часть дома, 7 = дача (`--realty-types 5 6 7`).
